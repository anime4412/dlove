## 🛠️ Hướng Dẫn Sử Dụng Bộ Công Cụ Chỉnh Sửa Dành Cho Shop

Hệ thống cho phép bạn tùy biến **100% nội dung và hình ảnh** để làm quà tặng bán cho từng khách hàng:

### 1. Hai Cách Chỉnh Sửa Trực Quan
* **Cách 1 (Nhanh nhất):** Mở link web [index.html](https://anime4412.github.io/dlove/) -> Bấm vào nút nổi **`⚙️ Chỉnh sửa nội dung & ảnh`** ở góc phải trên màn hình (hoặc bấm phím tắt **`F2`**).
* **Cách 2 (Chuyên nghiệp):** Mở trang [editor.html](https://anime4412.github.io/dlove/editor.html) để làm việc trên giao diện Studio chia đôi màn hình (bên trái chỉnh sửa, bên phải xem trước trên điện thoại mô phỏng).

---

### 2. Các Mục Tùy Biến Toàn Diện
1. **📝 Lời chúc & Chữ 3D:**
   * Tiêu đề hiển thị web (Browser Title).
   * 3 Dòng chữ hạt 3D biến hình theo kịch bản (VD: *"Chúc bé iu của anh"* - *"Ngày Phụ Nữ Việt Nam"* - *"vui vẻ !"*).
   * Có sẵn các mẫu 1-click: **🎂 Sinh Nhật**, **💐 20/10 & 8/3**, **💖 Kỷ Niệm Yêu**, **💌 Tỏ Tình / Valentine**.
2. **🌌 Ảnh hạt 3D trung tâm:**
   * Tải ảnh khuôn mặt / ảnh đôi / trái tim từ máy tính hoặc điện thoại. Hệ thống tự động nén nhẹ và phân tích điểm ảnh thành hàng ngàn hạt sao 3D phát sáng lung linh.
3. **🔮 12 Ảnh kỷ niệm quả cầu xoay 3D:**
   * Nút **"⚡ Tải nhanh 1-12 ảnh cùng lúc"**: Khách gửi ảnh qua Zalo, bạn chỉ cần chọn 1 lần là hệ thống tự điền vào 12 vị trí trong quả cầu.
   * Có thể đổi từng ảnh riêng lẻ trong lưới 12 ảnh.
4. **💌 Bức thư tình (Love Letter):**
   * Lời nhắn gửi (tự động gõ chữ tay từng ký tự lãng mạn).
   * Ảnh kỷ niệm kẹp trong thư (Polaroid).
   * Dòng chữ chú thích dưới ảnh (Caption).
5. **🔒 Mật khẩu mở khoá (Passcode):**
   * Bật/tắt màn hình khoá 4 số (VD: `2010`, ngày sinh của người nhận).
   * Tiêu đề & gợi ý mật mã.
6. **🎵 Nhạc nền:**
   * Bài hát *"Nơi này có anh"* chất lượng cao có sẵn.
   * Hoặc tải file MP3 tùy chọn từ máy tính/điện thoại, hoặc dán link nhạc online.
   * Thanh gạt chỉnh âm lượng (0% - 100%).

### 3. Giao Khách Hàng (3 Cách Giao Đơn Siêu Tiện)
* 📥 **Cách 1 — Xuất file HTML độc lập (Khuyên dùng nhất):**
  * Bấm nút **"Xuất file gửi khách"** -> Tải về file `index.html` (hoặc tên khách hàng).
  * Toàn bộ ảnh và lời chúc đã được đóng gói sẵn vào file.
  * **Hệ thống tự động loại bỏ thanh công cụ chỉnh sửa của Shop**, khách hàng mở lên chỉ thấy một món quà 3D hoàn mỹ!
* 💾 **Cách 2 — Lưu file cấu hình đơn hàng (.json):**
  * Tải file `.json` về máy để lưu trữ. Khi khách hàng đó muốn sửa đổi thông tin sau này, chỉ cần nạp lại file trong 1 giây!
* 🌐 **Cách 3 — Xuất bản qua GitHub Pages:**
  * Cập nhật file cấu hình vào GitHub repository để khách truy cập trực tiếp qua link online.
